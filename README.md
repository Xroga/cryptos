# OfCrypto — Landing Page

A fictional decentralized-finance brand landing page. Built as a static site with vanilla HTML, CSS, and JavaScript — no build step, no dependencies, instant preview.

> ⚠️ **Fictional project.** OfCrypto is not a real product. This page contains no real cryptocurrency, tokens, financial advice, or live data. It is a design demonstration only.

---

## ✨ Features

- **Hero section** — bold headline, tagline, dual CTAs, and animated stat counters
- **Features grid** — 4 selling points (Secure Transactions, Low Fees, Fast Transfers, Decentralized) with inline SVG icons
- **About section** — animated rotating "token" visual with orbiting nodes + brand copy
- **Final CTA** — email capture form with client-side validation (demo only, no backend)
- **Footer** — brand, nav, social links (Twitter / Discord / GitHub), copyright
- **Fully responsive** — mobile drawer nav, fluid type, adaptive grids for mobile / tablet / desktop
- **Animated constellation background** — canvas particle network with connection lines
- **Scroll-reveal animations** — staggered fade-up via `IntersectionObserver`
- **Accessible** — keyboard nav, ARIA labels, `prefers-reduced-motion` support, semantic HTML

## 🎨 Design

- **Type:** Syne (display) + Space Grotesk (body)
- **Palette:** deep-space `#06060d` base, mint `#00ffc6` → violet `#7c3aff` → pink `#ff3d8a` gradient accents
- **Effects:** glassmorphism cards, gradient glows, animated orb, rotating token rings
